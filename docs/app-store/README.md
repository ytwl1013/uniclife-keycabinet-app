# App Store 上架素材

本目录保存 App Store Connect 使用的截图与文案草稿：

- `screenshots/`：符合 iPhone 截图尺寸要求的 PNG 文件。
- `metadata/zh-Hans.txt`：简体中文推广文本、描述和关键词。
- `metadata/en-US.txt`：英文推广文本、描述和关键词。
- `metadata/routing-app-coverage-not-required.txt`：路由 App 覆盖地区字段说明。

文案应在上传前结合最终功能再次核对。钥匙柜应用不提供点到点导航，也未声明
`MKDirectionsApplicationSupportedModes`，因此不应上传 Routing App Coverage GeoJSON 文件。
