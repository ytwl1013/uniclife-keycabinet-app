
描述 / Description (≤4,000 characters)

```text
UnicLife 是配合受支持的 UnicLife 智能钥匙柜使用的钥匙管理应用。扫描二维码连接钥匙柜，即可集中查看钥匙状态、借用信息和活动记录。

主要功能
• 查看多个钥匙柜及可用钥匙槽位
• 登记钥匙和借用人
• 完成钥匙借出与归还
• 设置预计归还时间并识别逾期钥匙
• 按钥匙、借用人、钥匙柜或状态筛选
• 查看活动记录和重要操作历史
• 邀请管理员共同管理指定钥匙柜
• 接收逾期及账户管理提醒

本应用需配合受支持的 UnicLife 钥匙柜和有效账户使用。部分功能需要网络连接及相机权限；相机仅用于扫描受支持的二维码。
```
