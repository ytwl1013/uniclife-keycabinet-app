描述 / Description (≤4,000 characters)

```text
UnicLife is a key management app for supported UnicLife smart key cabinets. Scan a QR code to connect a cabinet, then view key status, borrower details and activity records in one place.

KEY FEATURES
• View multiple cabinets and available key slots
• Register keys and borrowers
• Check keys out and back in
• Set expected return times and identify overdue keys
• Filter records by key, borrower, cabinet or status
• Review activity records and important actions
• Invite administrators to manage a cabinet
• Receive overdue and account alerts

A supported UnicLife key cabinet and a valid account are required. Some features require an internet connection and camera access. The camera is used only to scan supported QR codes.
```
