```text
Gestiona préstamos, devoluciones y llaves vencidas en un solo lugar. Conecta tus armarios UnicLife y mantén cada operación visible y controlada.
```

描述 / Description (≤4,000 characters)

```text
UnicLife es una aplicación de gestión de llaves para armarios inteligentes UnicLife compatibles. Escanea un código QR para conectar un armario y consulta en un solo lugar el estado de las llaves, la información de los usuarios y el historial de actividad.

FUNCIONES PRINCIPALES
• Consulta varios armarios y las posiciones disponibles
• Registra llaves y usuarios
• Gestiona la retirada y devolución de llaves
• Establece la fecha prevista de devolución y detecta retrasos
• Filtra por llave, usuario, armario o estado
• Consulta el historial de actividad y las acciones importantes
• Invita a administradores para gestionar un armario
• Recibe avisos de retrasos y de gestión de la cuenta

Se requiere un armario UnicLife compatible y una cuenta válida. Algunas funciones necesitan conexión a Internet y acceso a la cámara. La cámara solo se utiliza para escanear códigos QR compatibles.
```
