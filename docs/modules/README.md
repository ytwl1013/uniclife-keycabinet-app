# 模块说明

## auth

登录、会话、角色和权限校验。权限判断必须在后端执行。

## users

用户、组织和人员映射。不得在日志中输出完整个人敏感信息。

## cabinets

钥匙柜、柜门、设备状态。硬件协议只允许通过 `backend/src/integrations` 适配器接入。

## keys

钥匙、钥匙位置和钥匙状态。领取和归还必须具备确认、幂等和审计记录。

## records

领取、归还、借用、盘点和异常记录。重复请求和部分失败必须给出明确结果。

## audit

审计日志、操作追踪和风险事件。审计日志记录追责所需信息，但不得记录不必要的敏感明文。
